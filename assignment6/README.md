## 📘 Question 1: Manual Test Case Report on Customer Relationship Management

Write a **manual test case report** for a **Customer Relationship Management (CRM) System**.

The report should include:
- Test case ID
- Test case description
- Preconditions
- Test steps
- Test data
- Expected result
- Actual result
- Status (Pass/Fail)
